# Static Results Workbook

The repository includes an Excel workbook generated from the project's verified analytical outputs.

**Artifact:** `dashboard/Employee_Attrition_Recruiter_Dashboard.xlsx`

It provides a presentation layer containing:
- executive KPIs;
- key business signals;
- cross-validation model comparison;
- held-out final evaluation;
- gender and age subgroup diagnostics;
- methodology and responsible-use notes.

The workbook is a **static results workbook**, not an interactive BI dashboard. The Python pipeline and committed CSV reports remain the analytical source of truth.
