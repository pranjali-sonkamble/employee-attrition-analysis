# Excel recruiter dashboard

The recruiter dashboard workbook is generated as:

`Employee_Attrition_Recruiter_Dashboard.xlsx`

It contains:
- Executive KPI view
- key business signals
- cross-validation model comparison
- held-out final evaluation
- gender and age subgroup diagnostics
- methodology and responsible-use notes

The workbook is a presentation layer over the verified project outputs; the repository's Python pipeline and CSV reports remain the analytical source of truth.

**Local artifact:** `Employee_Attrition_Recruiter_Dashboard.xlsx`
